# Draft inspection assets

`observatory.template.html` is the authored read-only inspection template. It requires its expected data element and is not a standalone product. The embedded original recorded snapshot/renderer/screenshot files are intentionally excluded from the default public export. `SPEC.md` preserves the draft journey and data boundaries; copied machine paths are explicitly sanitized.

`early-workflow-alternatives.html` is an earlier illustrative graph/timeline direction using hypothetical demo records. Do not attribute those records or response states to real agents. No UI choice or new frontend implementation is ratified by inclusion. This directory is source/reference material, not a hosted site, public dataset or deployment.
