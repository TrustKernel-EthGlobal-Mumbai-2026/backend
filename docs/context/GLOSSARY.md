# Repository search terms

Use these keywords with tools/context_index.py. This is terminology/navigation, not a new verification policy.

| Term / useful search | Meaning and source |
|---|---|
| **snapshot omission**; required snapshot; before-report obligation | `required_snapshot_invocation` checks the actual original prompt and invocation prefix. See live_verification/RULES_POLICY.md and LATEST_RUN.md. A missing result differs from an omitted call. |
| **live feedback**; corrective loop; hold refresh recheck | Real-agent finding delivery and correction remain the next milestone. The scripted synthetic loop exists in procedural_loop/; its success does not establish live intervention. |
| **baseline synthetic**; Hold versus Underweight | Actual model execution over identical authored evidence precedes a later native-source baseline. Different dates/data prevent a causal comparison. See SESSION_MAP.md and README. |
| **stale evidence**; freshness TTL; candle finality | Source time, acceptable age, finality and authority require explicit policy. The synthetic TTL60 is authored; it is not applied to live daily bars. See QUESTIONS.md. |
| **faulty extract**; numeric alignment; semantic support | Lexical/rounding agreement is a bounded check. Candidates and units/date/attribution remain provisional. See live_verification/ledger_extract.py and rules_checks.py. |
| **OHLC bounds**; close below low; bad provider row | Mathematical source-row inconsistency, with a run-local observation and exact source span. It is not automatically an agent fabrication. |
| **version disagreement**; CSV snapshot conflict | Different saved observations may disagree asynchronously. Discrepancy and acknowledgement are separate findings; content hash is not authoritative supersession. |
| **semicolon correction**; refinement3.0.1; branch attachment | The prior provisional cross-semicolon condition error was corrected by a local branch guard. See verification/REFINED_README.md and refine_rules.py. |
| **atomic ledger**; candidates; unresolved fragments | Stable source-aligned records and proposed structure, not a collection of accepted facts. See live_verification/LEDGER.md. |
| **source exposure**; input presence; tool-role lineage | Availability, retrieval, exact model input, source citation and material reliance differ. See live_verification/ledger_corpus.py. |
| **structured origin**; render replay | Recorded structured arguments reproduce saved report bytes and an observed subsequent step output. This closes a representation gap, not whole-decision support. |
| **clearance**; global validity; eligibility | Scoped results may bind an authored fixture version. Public live assessment has no global clearance; no trading authority follows. |
| **frontend draft**; observability; graph-led transparency | Inspect execution/evidence/intervention/gaps under the surface. Draft assets live in drafts/frontend/. |
| **sponsor CRE 0G Arkiv** | Historical investigation and preferences. No executed integration or verified current prize eligibility. |
| **BB8 snapshot**; portable skills; context retrieval | Frozen human-authored guidance in bb8/, not personal memory or guaranteed installed tools. Read bb8/README.md and AGENTS.md. |

For a current answer, open README and the relevant context document before following older historical matches. Search does not infer private reasoning or turn a highly ranked snippet into verified evidence.
